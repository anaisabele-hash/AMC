## Projeto AMC – Conhecendo o Hardware de um Computador ##

Introdução

A arquitetura de computadores estuda como os equipamentos são organizados e como suas peças trabalham juntas. Já a manutenção busca identificar problemas e garantir que os dispositivos continuem funcionando corretamente.

## Análise do equipamento ##

Durante a atividade, foi observado um computador desktop que ainda conseguia funcionar, mesmo apresentando a falta de alguns componentes. A análise permitiu identificar as peças presentes no gabinete e conhecer melhor sua configuração.

## Informações técnicas ##

As principais características do equipamento identificado foram:

- Placa-mãe: IPX1800E2
- CPU: Intel Celeron Dual-Core J1800.
- Velocidade do processador: 2,41 GHz.
- Memória: 4 GB de RAM DDR3.
- Disco de armazenamento: SSD de 120 GB.
- Sistema operacional compatível: Linux ou Windows 10/11 em versões leves.

## Função dos componentes ##

Cada parte do computador possui uma responsabilidade:

- Placa-mãe: conecta os componentes e permite a comunicação entre eles.
- Processador: executa instruções e realiza operações.
- Memória RAM: mantém temporariamente os dados utilizados pelos programas.
- SSD: armazena arquivos e informações.
- Sistema operacional: permite a interação entre o usuário e o computador.

Observações finais

A atividade mostrou que conhecer os componentes internos é importante para compreender o funcionamento de um computador. Também foi possível observar que a ausência de determinadas peças não impede necessariamente o funcionamento do equipamento, dependendo dos componentes que permanecem instalados.
